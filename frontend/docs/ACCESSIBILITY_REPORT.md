# WCAG 颜色无障碍测试报告

**项目**: CapyGlide 电动车租赁系统
**测试日期**: 2026-05-13
**测试标准**: WCAG 2.1 Level AA
**测试工具**: 理论计算 + 色彩对比度分析

---

## 1. 概述

本报告测试 CapyGlide 系统的主要配色方案是否符合 WCAG 2.1 AA 级无障碍标准。

**WCAG AA 标准要求**:
- 普通文本: 对比度 ≥ 4.5:1
- 大文本 (≥18pt 或 14pt 粗体): 对比度 ≥ 3:1
- UI 组件和图形: 对比度 ≥ 3:1

## 8. 测试方法说明

### 8.1 对比度计算公式

```
对比度 = (L1 + 0.05) / (L2 + 0.05)
其中 L = 0.2126 * R + 0.7152 * G + 0.0722 * B (相对亮度)
      R, G, B = sRGB 线性化值
```

### 8.2 测试限制

- 本报告基于理论计算
- 建议在实际设备上进行视觉测试
- 建议色盲用户参与测试
